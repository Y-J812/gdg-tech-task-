# Exam Intelligence Assistant — Vercel deployment

1. Upload all files in this folder to a GitHub repository.
2. Import the repository in Vercel and deploy. No BAT file is used.
3. Vercel serves `public/index.html`; `/api/analyse` is a Python serverless function.
4. Use the demo button to test the app.

This simple Vercel version accepts pasted questions and TXT/CSV/MD files. PDF parsing and OCR are not included. The priority score is a heuristic, not a prediction of exam questions.
